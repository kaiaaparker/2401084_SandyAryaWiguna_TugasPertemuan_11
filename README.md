# 2401084_SandyAryaWiguna_TugasPertemuan_11
Memodifikasi aplikasi hasil praktikum menjadi aplikasi pencatatan produk toko.
Cara Menggunakan Aplikasi
1. Pada halaman **Form**, isi nama produk, pilih kategori (Makanan/Minuman), dan isi harga berupa angka bulat, lalu klik **Simpan dan Lihat Detail**.
2. Halaman **Detail** menampilkan produk yang baru disimpan. Klik **Tambah Produk Lain** untuk menambah produk berikutnya.
3. Klik **Lihat Daftar** untuk melihat semua produk di tabel.
4. Ketik nama produk (dan pilih kategori) lalu klik **Cari** untuk mencari. Klik **Reset** untuk menampilkan semua data.
5. Pilih satu baris di tabel lalu klik **Lihat Detail** untuk membuka detail produk tersebut.

Aturan Validasi
- Nama produk tidak boleh kosong.
- Harga harus berupa angka bulat lebih dari nol.
